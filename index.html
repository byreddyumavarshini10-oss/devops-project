📖 About This Project

This project demonstrates the implementation of Frontend Web Development integrated with DevOps practices. The website is developed using HTML, CSS and JavaScript. Git is used for version control, GitHub stores the source code, and Netlify automatically deploys every update, demonstrating a Continuous Integration and Continuous Deployment (CI/CD) pipeline. This project helps students understand how automation improves software delivery and reduces manual deployment efforts.
